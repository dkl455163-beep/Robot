# Robot

一个 AI 语音对话机器人项目。前端使用浏览器语音识别获取文本，后端调用 AI 模型并以流式方式返回结果，最后通过浏览器语音合成进行播报。

## 技术栈

- HTML
- CSS
- JavaScript
- Speech Recognition API
- Speech Synthesis API
- SSE 流式响应
- Java 后端接口

## 已实现功能

- 语音识别
- 空格键控制录音
- AI 回复流式展示
- 语音合成播报
- 加载状态和错误提示

## 项目文件

- `text.html`：页面结构
- `text.css`、`text2.css`：页面样式
- `text.js`：语音识别、请求发送和语音播报
